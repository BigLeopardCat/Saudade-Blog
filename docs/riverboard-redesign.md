# 河灯页：场景、交互与渲染重构

场景采用东方夜河的电影感构图：远山、岸边建筑和月色作为静态美术层，水面流动、烛光倒影、漂流河灯、点击涟漪、轻雾与萤火作为动态层。默认“沉浸”档，另提供“节能”和“静谧”，不以隐藏所有效果换取性能。

## 渲染结构

- `LanternArt.tsx`：三款灯共用一张透明 atlas；材质为莲瓣、朱漆六角宫灯、素纱圆灯，移除每盏灯的独立火焰混合、光池与圆环动画层。
- `useRiverScene.ts`：仅绘制下半河面，背景图和水面共用 cover 几何；水纹通过缓存纹理条带位移，暖光/倒影/萤火共用预烘焙光斑，点击涟漪有数量与寿命上限。
- `sceneBudget.ts`：沉浸 30 fps / 最大 1440 像素宽，节能 24 fps / 最大 960，静谧没有持续帧循环。画布尺寸不随 DPR 或 144 Hz 显示器无上限增长。调度器只保留一条 timer/rAF 链。
- `useDialogFocus.ts`：弹窗焦点约束、Escape 和关闭后焦点恢复。打开弹窗或页面隐藏时暂停场景，恢复时不积分隐藏期间的时间。减少动效偏好实时生效；卸载取消所有调度与监听器。
- `cinematic.scss`：独立的场景与 HUD 样式；雾仅改变 transform/opacity，暂停和静谧模式会一并停止。保留纸笺弹窗的阅读对比度。
- RiverBoard 路由按需加载，场景资源不进入其他页面的初始依赖；助手由用户主动唤起，避免新进入此页时额外启动 Live2D。此前已经在 SPA 中启动的全局助手仍沿用既有生命周期。

1440×900 视口下，新沉浸档画布 backing store 为 1224×367（449,208 像素），旧画布在 DPR=1 时为 1440×900（1,296,000）。这只是可验证的绘制预算缩减，不是 GPU 利用率下降百分比。保留的动态内容、合成器、浏览器与显卡仍影响实际负载。

本实现为分层场景与图像折射式水面动画，不是完整三维引擎；目标是美术观感、互动氛围与可控成本。没有宣称达到实时光线追踪或某款 3A 游戏的渲染规格。

## 业务与交互

保留公开留言、放灯三步流程、灯影集、我的河灯、审核状态、收回、通知链接定位。待审/驳回灯不产生水面光照。示意灯与真实留言加载失败明确区分；初始成功空列表显示真实空态。放灯失败显示原因、保留文本；提交结束清除忙碌状态，避免成功后无法通过 Escape 关闭。提交在途避免误退出或切回上一步。

手机横竖屏、安全区、键盘 Enter/Space 读灯、弹窗 Tab 循环与关闭后焦点恢复均有浏览器回归。用户输入使用 React 文本节点呈现。

## 验证方式

```bash
cd frontend
npm ci
npm run fetch:widget
npx tsc --noEmit -p tsconfig.json
npm test
npm run lint
```

`tests/riverboard-scene.test.mjs` 测试画布预算、cover 裁剪、144 Hz 主机上的限频、暂停/恢复、静谧以及销毁，替换了已删除月盘渲染器的专用测试。旧月相贴图生成器和没有消费方的载荷同步移除。

浏览器回归独立运行，不访问生产 API；所有 API 均被测试夹具拦截，包括 POST：

```bash
npm run dev -- --host 127.0.0.1 --port 5174
# 另一个终端，Playwright 安装位置可通过 PLAYWRIGHT_MODULE_PATH 显式提供：
RIVER_TEST_URL=http://127.0.0.1:5174/guestbook node tests/riverboard.browser.mjs
```

覆盖桌面/手机横竖屏、点击水面、公开阅读、未登录门禁、完整放灯待审流程、弹窗焦点与暂停、静谧/减少动效/隐藏恢复、加载失败与重试/空态、无默认助手启动及无页面异常。截图目录由 RIVER_SCREENSHOTS 指定。生产 GPU 占用需要在真实浏览器与显卡上对比，此开发环境使用 Chromium SwiftShader，不能把软件渲染进程 CPU 当作用户显卡 GPU 指标。

本轮未在共享主机运行生产构建或修改 Nginx、服务及数据库。
