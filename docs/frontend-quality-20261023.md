# 前端加载与管理交互改进（2026-10-23）

本批承接审计 FE5、FE9 与测试规范审查，排除 IoT。

路由：后台壳与各管理页、编辑器、分析图表、阅读页及非首页内容改为 lazy，页面级 Suspense 保留公共布局；编辑器依旧按文章 id 换实例，鉴权在后台 lazy 内容外。主页与公共壳保留同步加载。包体与生产构建由 PR CI 核验，未在共享生产机 build，未承诺移动设备 LCP 或 GPU 指标。

首页：分页控制器只接受确认成功且形状合法的响应；网络/业务失败保留列表、页码与 hasMore，不缓存失败空数组；提供重试、单飞与代际隔离，屏幕列数切换失败先重试第一页。置顶加载失败与成功空态独立，轮播索引跟随列表收敛。后端部分列表仍将 DB 错误转成功空数组，客户端无法识别这一类错误，需后续后端契约修复。

管理交互：分类以搜索列表、明确新增/编辑弹窗、图标选择、配色预览、路径建议与清楚的删除影响代替旧浮动按钮与技术字段。标签明确区分创建/编辑与勾选批删，主/子标签与所属主题用自然中文表达；保留按层级的业务身份，避免两个表 id 相同而错改/错删。

测试迁移分批进行，具体命令、验收与剩余范围见 [前端测试规范](frontend-testing.md)。本批不会关闭 PR #34 或删去全部历史回归。对实际组件已有等价覆盖后才退役旧 Python 或手写 hooks harness；运行产物不提交。

河灯后续调整：根据使用者真实显卡反馈移除公开三档画质控件，使用单一动态场景；WebGL 水面把连续法线、局部波前、二维折射、月光和各灯的暖反射一起求值，火焰/纸内光与水面亮度共用每灯独立相位。上限 45 FPS、1600px 水面宽度并扩大动态水域，保留隐藏/弹窗暂停与减少动效。无 WebGL 时提供 2D 降级，着色器/上下文失败露出底景并停止循环。它仍使用美术底景供场景采样，不是光追或完整 3D 流体，也未将软件渲染器的占用当硬件 GPU 结果。
