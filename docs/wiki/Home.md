# 博客：从零部署、读懂和使用

这是从第一次安装到日常内容管理的使用手册。核心博客不要求启用 Agent、模型或 R2，先用基础功能，再按需求接入。

## 推荐顺序

第一次使用按“安装 → 配置 → 分类标签 → 写作发布 → 用户与公告 → 可选 Agent”阅读。已有站点从对应功能或升级步骤开始。

截图来自真实组件的隔离浏览器场景，使用合成账号、示例域名与占位图片，不是生产后台或真实生图质量证明。
每张图放在对应步骤旁；先看图下说明，再按自己的账号和版本操作。配置密钥不会出现在截图中。
