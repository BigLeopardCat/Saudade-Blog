# 阅读、检索与日常互动

## 阅读与查找

首页文章靠近底部自动加载下一批；失败时保留已加载内容，使用重试继续。
看到“已经看到全部文章了”表示这次列表读到末尾，不把加载失败当成没有文章。
可通过分类、标签、归档或聚合检索找文章，核对结果类型和真实链接。

文章中的 Mermaid 图表可点击或键盘聚焦后回车放大，滚轮/双指缩放和拖拽查看，关闭后继续阅读。
普通检索与 Agent RAG 是不同链路；向量图谱入口暂停不等于普通检索不可用。

## 收藏与评论

登录自己的账号后使用收藏和个人中心管理。取消自己的收藏不影响文章原文。
评论或留言提交前检查内容；审核中不等于已公开，禁言与权限限制也不靠反复提交解决。

## 河灯、说说与审核

河灯留言使用前台入口，核对发布状态和提示；界面中的动画不代替业务保存。
说说和后台内容管理受账号权限约束，不因人设或昵称变化获得管理员能力。
管理员处理留言/评论时读全文、核对目标与理由，再审阅审核或删除操作。

## 通知、站内信与额度

个人中心分别查看通知、站内信和未读汇总。打开正文、标为已读、删除副本是不同操作。
对话额度不足时从个人中心「对话额度」提交申请，等待管理员处理；不能靠新建会话绕过账号额度。
详见[公告与消息](https://github.com/BigLeopardCat/Saudade-Blog/wiki/Announcements-and-Messages)。
