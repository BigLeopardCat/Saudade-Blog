# 使用指南

本页描述当前界面；首次部署见[快速开始](../README.md)，管理员配置见[运维](deployment-and-ops.md)。

## 写作与封面

1. 在后台文章管理打开或新建文章，编辑标题、Markdown 正文和摘要。
2. 从图库选择封面，按图片内容选择铺满裁切或完整显示。海报、竖图和带文字图片优先完整显示，必要时留边。
3. 检查草稿保存状态后打开发布设置并确认。版本冲突时重新读取并合并，避免覆盖其他编辑。

## 图库与 AI 生图

1. 图库可建立文件夹，按分类浏览；点击缩略图查看详情，批量选择需主动勾选。
2. 详情内可查看图片、修改文件名和描述、移动、收藏或删除。描述有助于搜索和 Agent 选择图片。
3. 管理员打开 AI 生图，填写提示、模型、尺寸/质量并选参考图。审核准确参数后批准生成，此时才可能产生费用。
4. 查看生成结果，决定入库或拒绝。入库不自动更换文章封面；需要时另外选择封面。

模型密钥由服务器配置。未配置或模型无权限时界面应显示原因；结果未知时先核实，不要连续点击重复生成。

## 看板娘对话

可让助手找文章、解读当前页面、导航，管理员还可管理站内数据或协作编辑。执行中可补充要求；暂停后可继续同一任务，页面断连不意味着外部请求已取消。

![聊天窗口示意](assets/chat-workspace.png)

界面截图使用合成数据。聊天图片保留完整比例并限制预览大小，点击放大；发送前的附件预览也可查看和逐个移除。

写入前核对确认卡的对象与内容。同类批量操作可逐项选择；不同事务可能分卡确认。取消后若要查看对象当前状态，应让助手重新查询。

协作文章时先打开编辑器，让助手读取内容，再提出标题/正文修改并审阅差异。摘要通过聊天确认卡批准后应用。需要发布时可在当前编辑页继续发布，无需退出再保存。

## 消息与检索

个人中心分别查看通知、站内信与未读汇总。先查看内容，再使用对应操作；删除消息不代表删除原始文章、公告或业务对象。

聚合检索提供多类型内容结果，可切换分类查看已有查询结果；向量图谱是可选的文章关联浏览。外部向量服务未启用时，普通检索与文章阅读仍可使用。

## 教程放在哪里

本页和配置、接口、发布说明随版本维护，便于贡献者在 PR 中同步。长篇场景教程、视频和更多截图可扩展到 Wiki，但应链接仓库的规范说明，避免重复维护相同配置与能力清单。
