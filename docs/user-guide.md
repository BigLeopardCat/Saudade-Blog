# 使用指南

本页描述当前界面；首次部署见[快速开始](../README.md)，管理员配置见[运维](deployment-and-ops.md)。
按任务逐步操作的教程见[Wiki 源稿](wiki/Home.md)与[在线 Wiki](https://github.com/BigLeopardCat/Saudade-Blog/wiki)。

## 首页阅读

文章列表接近底部时自动加载下一批；失败时保留已加载文章，点击“重试”继续。看到“已经看到全部文章了”表示本次浏览到达末尾。

置顶区可混排文章与公告；后台「公告」列表可开启或取消公告置顶。公告卡片突出发布时间，点击可展开正文。置顶内容以带编号的横向卡片连续轮播，底部分段细条同步显示进度。悬停某段可预览对应卡片组，点击跳转；鼠标停留在卡片、细条或预览窗口，以及键盘焦点停留时暂停。手机支持滑动切换，系统开启减少动态效果时停止自动播放。置顶内容数量不足一屏时直接展示全部卡片。

文章中的 Mermaid 图表默认完整显示在阅读区域内；点击或聚焦后按回车可打开查看器，初始也显示整张图。滚轮、双指缩放和拖拽可查看细节，双击切换整图与细节；手机旋转屏幕后重新适配。

## 写作与封面

1. 在后台文章管理打开或新建文章，编辑标题、Markdown 正文和摘要。
2. 从图库选择封面，按图片内容选择铺满裁切或完整显示。海报、竖图和带文字图片优先完整显示，必要时留边。首页卡片与置顶卡片共用 4:3 封面比例；裁切面板渲染实际卡片，标题、摘要、标签与当前编辑内容同步，详情横幅另行预览。
3. 检查草稿保存状态后打开发布设置并确认。版本冲突时重新读取并合并，避免覆盖其他编辑。

## 图库与 AI 生图

1. 图库可建立文件夹，按分类浏览；点击缩略图查看详情，批量选择需主动勾选。
2. 详情内可查看图片、修改文件名和描述、移动、收藏或删除。描述有助于搜索和 Agent 选择图片。
3. 管理员打开 AI 生图，填写提示、模型、尺寸/质量并选参考图。审核准确参数后批准生成，此时才可能产生费用。
4. 查看生成结果，决定入库或拒绝。入库不自动更换文章封面；需要时另外选择封面。

模型密钥由服务器配置。未配置或模型无权限时界面应显示原因；结果未知时先核实，不要连续点击重复生成。

## 看板娘对话

可让助手找文章、解读当前页面、导航，管理员还可管理站内数据或协作编辑。执行中可补充要求；暂停后可继续同一任务，页面断连不意味着外部请求已取消。

单击顶部栏可收成一条可拖动栏，隐藏按钮直接贴到页面顶部，再点击展开。
宽屏文章页可自动使用侧栏布局，仍能拖动和缩放；关闭后同一文章的布局更新不会反复拉开窗口。
收起或关闭仅改变展示，不撤销确认，也不证明任务已经停止。

![聊天窗口示意](assets/chat-workspace.png)

界面截图使用合成数据。聊天图片保留完整比例并限制预览大小，点击放大；发送前的附件预览也可查看和逐个移除。

阅读聊天历史时，收到新消息才出现提示；点击提示回到最新消息后恢复自动跟随。图片加载、旧记录展开与窗口缩放不会产生新消息提示。

写入前核对确认卡的对象与内容。同类批量操作可逐项选择；不同事务可能分卡确认。取消后若要查看对象当前状态，应让助手重新查询。

协作文章时先打开编辑器，让助手读取内容，再提出标题/正文修改并审阅差异。摘要通过聊天确认卡批准后应用。需要发布时可在当前编辑页继续发布，无需退出再保存。

## 消息与检索

个人中心分别查看通知、站内信与未读汇总。先查看内容，再使用对应操作；删除消息不代表删除原始文章、公告或业务对象。

聚合检索提供多类型内容结果，可切换分类查看已有查询结果。文章向量图谱暂停提供，普通检索、文章阅读与 Agent RAG 检索照常使用。
