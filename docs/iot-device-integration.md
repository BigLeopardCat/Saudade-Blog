# 可选设备演示

IoT 是独立可选演示，默认关闭。核心博客不依赖 MQTT、设备服务或 ESP32。

安装、服务配置和固件步骤见 [iot/README.md](../iot/README.md)。启用时同步设置博客和 Agent 的 `IOT_ENABLED`，并配置实际设备服务地址；未安装时保持关闭，不显示无法使用的能力。

设备服务自行校验服务端身份和业务权限，只绑定受控地址。设备控制只能通过已授权工具调用，不能从聊天文本直接执行命令。演示代码不应被视为生产设备平台，扩大用途前需独立审计。

设备故障应影响对应演示，不能阻塞文章阅读、后台管理和普通聊天。相关诊断使用 `iot/status.sh`，避免在日志或截图中暴露凭据。
