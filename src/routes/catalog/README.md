# 管理员只读名录

`GET /api/protected/accounts` 使用标准管理员授权，只投影编号、登录名、昵称、角色及状态/额度元数据。
不返回密码、邮箱或登录凭据。隐藏角色在计数和分页之前排除，按编号升序稳定分页。

- `id`、`username` 是精确筛选；登录名保持大小写及原值，不把昵称猜作登录名。
- `query` 在登录名和昵称上作不区分大小写的连续字串检索；`%`、`_` 和反斜杠按原字符匹配。
- 多个筛选条件取交集。返回匹配总数；没有结果仅表示该授权范围和筛选条件下没有匹配。
- 检索词最多 100 字符，完整登录名最多 255 字符。拒绝无效编号、空检索及未支持的参数。
- 默认及最多每页 20 条，页码及边界复用 `routes::pagination`。

检索只提供候选，不自动选择写入目标。修改账号仍使用 `account-actions` 的明确编号/完整登录名、
版本核验、授权和事务；昵称不会进入写操作目标解析。

测试覆盖绑定参数、特殊字符、大小写、昵称候选、分页、角色过滤与字段投影。
`TEST_PG_URL` 指向 CI 临时 PostgreSQL 时执行事务回滚测试，不读取生产连接配置。
